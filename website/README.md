# Pickwell website starter

This inherited Astro/React marketing starter belongs to the owner's StartAppLab
foundation. It is **not the Flutter hackathon demo** or evidence of a deployed
Pickwell marketing site, store availability, testimonials or customer metrics.
See the [root README](../README.md) for the actual project.

For optional starter development, use Node.js 20.18+ and pnpm, from this directory:

```sh
pnpm install --frozen-lockfile
cp env.example .env
pnpm dev
```

Supply only your own public SDK configuration in the ignored `.env`; values with
`PUBLIC_` are browser-visible. No Meta/service-role credentials belong there.
`package.json` defines `pnpm build`, `pnpm preview` (build plus Wrangler local
preview), `pnpm astro` and Cloudflare deployment commands. Deployment requires a
separate authorized task; none was performed during repository remediation.

Retained template copy, store badges and provider marks are not claims of live
Pickwell integrations or store approval. Review provider marketing terms before
publishing this website. See [third-party notices](../THIRD_PARTY_NOTICES.md),
including icon attribution and unresolved historical artwork provenance.
