# Repository instruction pointers

Before working in a project folder, read its applicable `AGENTS.md`:

- Flutter mobile app: [mobile/AGENTS.md](mobile/AGENTS.md)
- Next.js web app: [web/AGENTS.md](web/AGENTS.md)
- Astro website: [website/AGENTS.md](website/AGENTS.md)

Check for additional nested `AGENTS.md` files in the folders you work on and
follow the instructions applicable to each file. For work spanning projects,
read each affected project's instructions.

For folders without their own `AGENTS.md`, inspect the relevant README and
project documentation. Do not assume another project's instructions apply.
